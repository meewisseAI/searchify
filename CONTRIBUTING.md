# Contributing

Issues and pull requests are welcome.

- Install in editable mode with the dev extra: `pip install -e ".[dev,api]"`.
- Run the tests: `pytest`.
- Keep the public API small and documented; add a test for new behavior.
- Do not add API keys, hosts or personal data to the repo. All credentials come
  from the environment (see `.env.example`).
